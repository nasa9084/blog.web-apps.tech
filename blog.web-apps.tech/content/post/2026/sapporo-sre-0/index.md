先だって、株式会社クラスメソッドさんの札幌オフィスで、SREの勉強会である[Sapporo.sre #0](https://sapporo-sre.connpass.com/event/401379/)を開催し、登壇しました。
なんかSRE NEXTで札幌勢が結構いて、[はくすけ san](https://x.com/hacusk)がやるぞ！って言ってくれたみたいで、それをうけた[Yuidyy san](https://x.com/Yuidyy_555)が突然私にメンションしてきたことにより登壇することとなりました。

そうはいっても札幌にはそんなにSREいなさそうだし、飲み会+αくらいの感じかな〜なんて言っていたら、8月の時点で既に満員御礼、最終的に会場のキャパギリギリまで枠を拡大して、それでもほぼ満員御礼、という感じで、はじめから#1で良かったんじゃないかな、という位の大盛況でした。

登壇内用は、Sapporo.sre初開催ということで、キャッチーなネタを選ぼうと思い「あけおめLINE 傾向とその対策」というタイトルで、LINEのあけおめスタンプ爆撃に対して、我々がSREとしてどのように準備をしているのか、という内容についてお話ししました。
11月の[YAPC::Tokyo](https://yapcjapan.org/2026tokyo)でも同じネタで、倍の時間で登壇しますので、みんな聞きに来てね。
